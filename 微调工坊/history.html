History & People · 历史与人物

写库的人，回过头教你用库

这本书的特殊之处：作者不是旁观者写的教程，是 transformers 库的核心开发者自己下场，把自己维护的工具写成教材。这既是它权威的原因，也是理解它"生态本位"视角的关键。

Timeline · 从聊天机器人到教育出版

一家公司的两次转型，一本书的诞生

2015

知识蒸馏被重新点燃

Geoffrey Hinton、Oriol Vinyals、Jeff Dean 发表《Distilling the Knowledge in a Neural Network》（arXiv:1503.02531），提出用"软标签 + 温度缩放"把大模型的知识压缩进小模型。这套方法的雏形更早由 Buciluă、Caruana、Niculescu-Mizil 在 2006 年提出，但 2015 年这篇让它成为深度学习时代的标准工具，也是本站第五个概念的直接源头。

2016

Hugging Face 成立

Clément Delangue、Julien Chaumond、Thomas Wolf 在纽约创立 Hugging Face，最初产品是一款面向青少年的聊天机器人 App，与后来的 NLP 工具生态几乎没有关系。

2017

Transformer 架构发表

Vaswani 等人发表《Attention Is All You Need》，提出完全基于注意力机制的 Transformer 架构，为一年后的 BERT 与两年后 Hugging Face 的转型埋下伏笔。

2018–2019

从聊天机器人到 transformers 库

Google 发布 BERT 后数周，Hugging Face 发布 PyTorch 重实现 pytorch-pretrained-bert（2018 年 11 月）；随着支持的模型家族扩大，2019 年 7 月改名 pytorch-transformers，同年 9 月定名 transformers。公司的主业务也随之从聊天机器人彻底转向开源 NLP 生态。

2021

LoRA 论文发表

Edward Hu 等人在微软研究院发表《LoRA: Low-Rank Adaptation of Large Language Models》（arXiv:2106.09685），提出用低秩矩阵近似权重更新，训练参数量可比全参微调少几个数量级。这篇论文出版时，本书写作已接近尾声，成为书中未覆盖但后续必须补的一块。

2022

《Natural Language Processing with Transformers》出版

O'Reilly 出版，三位 Hugging Face 工程师执笔，406 页，是 transformers 库自 2019 年发布三年后第一本系统性的官方实战教材。同年底 Hugging Face 首发 peft 库。

2023 至今

PEFT/LoRA 生态成为默认选项

peft 库随 LoRA/QLoRA 热潮迅速成为微调标配，本书里"少标注数据怎么办"一章给出的答案（零样本/少样本/UDA/蒸馏）不再是唯一选项——这是本站反复强调的时代局限，详见效率与生态精读页。

Debate · 学派论争

高层封装 vs 原生手写：一场没有输家的争论

围绕 Hugging Face 生态，工程界有一条长期存在的分歧：高层封装路线（Trainer、pipeline 一类一行调用的抽象）让工程师快速产出结果，但代价是隐藏了训练循环内部的细节——学习率怎么变、梯度怎么裁、损失怎么算，全被封装掉了。原生手写路线（自己写 PyTorch 训练循环，参见 书架另一站《从零炼模》 里 Sebastian Raschka 的做法）则要求你理解每一行代码在做什么，代价是慢、易错。

这本书选择了折中：先用高层 API 快速跑通四个任务（第 2、4、6、9 章），再用整整一章（第 3 章 Transformer Anatomy）把 Trainer 内部拆开讲清楚。批评者的意见集中在——如果读者只停留在调 API 的层面，遇到训练不收敛、显存溢出这类问题时会完全无从下手。这也是本站把"任务头替换"和"Trainer 三段式"分成两个独立概念的原因：知道怎么用和知道用的是什么，是两件事。
